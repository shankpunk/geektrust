# Power of G-Man

Solution to the [Geektrust "Power of G-Man" challenge](https://www.geektrust.com/coding/detailed/power-of-g-man).

## Problem
G-Man starts with a fixed power. Moving from a source to a destination on a grid reduces power based on **distance traveled** and **turns made**. The task is to calculate and print the remaining power.


## Run Instructions
1. Install Python 3.  
2. Clone this repo.  
3. Run with an input file:

```bash
python geektrust.py <absolute_path_to_input_file>
